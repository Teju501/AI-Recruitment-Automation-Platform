# Database

This folder contains the MySQL database schema
used in the AI Recruitment Automation Platform.

## Database Details

- Database Name: resume_ai
- Table Name: ats_results

## Stored Information

- Candidate Name
- Email
- ATS Score
- Job Match Percentage
- Recommended Role
- Matching Skills
- Missing Skills
- Interview Questions
- Selection Status
- Candidate Rank
- Created At
